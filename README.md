## About me

I'm a developer who likes turning ideas into working products — from **real-time web platforms** and **privacy-first browser tools** to **AI-assisted creative software**.

- I enjoy building polished interfaces backed by practical, maintainable systems.
- My strongest playground is the JavaScript / TypeScript ecosystem, with React, Next.js, Angular and Node.js.
- I also work with Java, MongoDB, REST APIs, WebSockets and modern frontend tooling.
- I care about software that still behaves well when networks, APIs or external services do not.
